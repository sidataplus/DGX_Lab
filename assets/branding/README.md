# DGX Lab Branding Starter

The icon is an original terminal-prompt motif with a green simulation-status light. It deliberately avoids NVIDIA logos, type treatments, and copied DGX product imagery.

## Sources and generated outputs

- `dgx-lab-icon.svg`: editable vector source.
- `app-icon-1024.png`: master raster source.
- `src-tauri/icons/`: Tauri desktop bundle sizes (`PNG`, `ICO`, and `ICNS`).

The current visual identity is a developer-pack baseline, not a final trademark or accessibility review. Before public distribution, review the product name, icon distinctiveness, contrast at small sizes, and platform store requirements.
