# Course and Competency Map

| Module | Primary competency | Practical outcome |
|---|---|---|
| 01 | Cluster fundamentals | Explain node/partition/job/step |
| 02 | Interactive jobs | Acquire and release CPU allocation |
| 03 | CPU/RAM and isolation | Request and diagnose memory |
| 04 | GPU allocation/isolation | Request one GPU and verify visibility |
| 05 | Containers | Run synthetic GPU workload reproducibly |
| 06 | Batch jobs/logs | Convert prototype to `sbatch` |
| 07 | Scheduling | Diagnose pending reason under contention |
| 08 | Arrays/dependencies | Orchestrate a small campaign |
| 09 | Troubleshooting/checkpoints | Recover after failure |
| 10 | Distributed training | Launch/interpret four-GPU workload |
| 11 | Policy/efficiency | Interpret limits and right-size resources |
| 12 | Capstone | Operate a robust end-to-end campaign |

Certification samples every knowledge domain and uses practical scenarios from Modules 04, 07/08, and 09/12.
