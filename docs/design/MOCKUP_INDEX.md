## Implementation cautions

- Do not rely on tiny text density or color alone.
- The certification mockup says “proctored”; standalone v1 is **not** remotely proctored. Use “protected local assessment” unless an instructor/institution mode supplies a trusted process.
- Always retain the visible statement that resources are simulated.
