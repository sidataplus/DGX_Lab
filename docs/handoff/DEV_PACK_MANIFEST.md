# Dev Pack Contents

This ZIP is a source-and-documentation development pack, not a compiled release. It includes the complete PRD, four approved mockups, Rust/Tauri/WASM walking skeletons, a functional static prototype, declarative content, schemas, validators, CI blueprints, ADRs, runbooks, and handoff documentation.

Run `python3 scripts/generate_manifest.py` to regenerate `MANIFEST.sha256` after modifications.

## Primary handoff documents

- `PACK_BUILD_REPORT.md`: exact pack inventory, validation evidence, and first build-host sequence.
- `IMPLEMENTATION_STATUS.md`: implemented versus unverified surfaces.
- `BUILD_GAPS.md`: transparent compilation and packaging gaps.
- `NEXT_ACTIONS.md`: ranked continuation work.
- `REQUIREMENTS_TRACEABILITY.md`: all 241 PRD requirement IDs.
