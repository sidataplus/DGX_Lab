# Product Roadmap

## Smallest useful version

Four labs: cluster mental model, interactive CPU, CPU/memory, one GPU. One generic profile, one real learner, scripted virtual users, virtual shell/VFS, deterministic scheduler, local persistence, and reset.

## v1.0

Twelve labs, sandbox, arrays/dependencies, synthetic containers and PyTorch workloads, failure recovery, multi-GPU, accounting, certification, portable evidence, accessibility, and desktop packages for the three major platforms.

## Near-term post-v1

- Thai UI/course pack;
- QOS, reservations, simplified multifactor priority and fair-share;
- adaptive deterministic actors;
- rewind/branch simulation;
- official content pack signing;
- static PWA edition;
- instructor evidence review tool that remains offline.

## Long-term

- fictional multi-node topology and synthetic NCCL behavior;
- GPU sharing/MPS/MIG teaching profiles;
- LMS export and institutionally signed certification as separate trusted services;
- classroom mode as a separate architecture, not hidden multiplayer in the standalone product.

## Explicitly out of scope

- real scheduler connection;
- arbitrary code execution;
- real containers or Python;
- cloud account/progress dependency;
- AI/LLM tutor in core learning or grading;
- public content marketplace in v1.
